# 翁法罗斯 · 永恒之地

> *崩坏：星穹铁道 — 翁法罗斯（Amphoreus）同人资料站*

三重命途交汇的模拟世界——智识、记忆、毁灭。英雄流淌着金色的神血，踏上了逐火之旅。

## 📖 项目简介

一个沉浸式的翁法罗斯资料展示页面，涵盖世界观设定、城邦地理、泰坦谱系、黄金裔角色档案等完整内容。

**✨ 特性：**
- 粒子动画首页 | 时代之河时间线
- 城邦轮播全屏展示（含 BGM 自动切换）
- 泰坦弧形排列 + 点击聚焦详情面板
- 黄金裔「如我所书」角色画廊
- 背景音乐系统（地区 BGM + 角色主题曲）

## 🛠️ 技术栈

- 纯前端（HTML + CSS + JavaScript）
- Canvas 粒子动画
- SVG 时间线绘制
- 响应式设计
- 无外部依赖

## 🚀 快速开始

直接打开 `index.html` 即可浏览，或使用任意静态服务器：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
